# Components

Reusable UI primitives will live here. Planned components:

- `Button.tsx` — Primary / secondary / ghost variants with loading state
- `Card.tsx` — Base card surface with shadow and rounded corners
- `RestaurantCard.tsx` — Feed card with hero image, rating, delivery info
- `MenuItemCard.tsx` — Horizontal item card with price and add button
- `Badge.tsx` — Cuisine / status tags
- `Rating.tsx` — Star rating display with count
- `QuantityPicker.tsx` — Increment / decrement stepper
- `CartTray.tsx` — Sticky bottom bar showing cart summary

Add these as you build each screen.
